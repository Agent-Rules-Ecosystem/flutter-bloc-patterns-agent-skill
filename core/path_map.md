# 🗺️ Mapa de Rutas BLoC en Flutter

- `lib/logic/blocs/` o `lib/blocs/`: Directorio central de BLoCs por característica.
- `lib/logic/cubits/` o `lib/cubits/`: Directorio central de Cubits.
- `lib/data/repositories/`: Repositorios de datos consumidos por BLoCs.
- `test/logic/blocs/` / `test/blocs/`: Pruebas unitarias de BLoC con `bloc_test`.
