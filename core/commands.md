# ⚡ Comandos de BLoC ($bloc)

- `$bloc`: Bootstrap de habilidades de BLoC para Flutter.
- `$bloc:create [nombre]`: Genera plantilla completa de BLoC (Event, State, Bloc, Repo).
- `$bloc:cubit [nombre]`: Genera plantilla de Cubit ligero.
- `$bloc:hydrated [nombre]`: Convierte BLoC a HydratedBloc para persistencia local.
- `$bloc:audit`: Auditoría de arquitectura reactiva, memory leaks y rebuilds.
- `$bloc:test [nombre]`: Genera suite de pruebas unitarias con `bloc_test`.
